# AI-Native Knowledge Repository

Ce repository est un **Knowledge Repository** : il centralise la connaissance d'un projet (vision, produit, modèle métier, architecture, décisions) pour que les humains et les agents IA puissent s'y appuyer.

Il ne contient **pas de code applicatif**. Pas de dépendances, pas de build, pas de déploiement ici.

Le code vivra dans un **repository séparé**, lié à celui-ci par la documentation et le contexte partagé.

## Structure

| Dossier | Rôle |
|---------|------|
| [00-foundation/](00-foundation/) | Vision, principes, règles, glossaire |
| [01-product/](01-product/) | Proposition de valeur, modules, personas |
| [02-domain-model/](02-domain-model/) | Concepts métier, relations, cycle de vie |
| [03-business/](03-business/) | Stratégie marché et modèle économique |
| [04-architecture/](04-architecture/) | Structure technique |
| [05-decisions/](05-decisions/) | Architecture Decision Records (ADR) |
| [playground/](playground/) | Brouillons avant intégration |
