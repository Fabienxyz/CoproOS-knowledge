# Start here

Parcourez ce repository dans l'ordre suivant :

1. **[MASTER_CONTEXT.md](MASTER_CONTEXT.md)** — vue d'ensemble exécutive du repository et point d'entrée pour les assistants IA.
2. **[AGENTS.md](AGENTS.md)** — règles de gouvernance pour les assistants IA travaillant dans ce repository.
3. **[README.md](README.md)** — comprendre ce qu'est un Knowledge Repository et son rôle par rapport au code.
4. **[00-foundation/vision.md](00-foundation/vision.md)** — vision long terme du projet.
5. **[00-foundation/](00-foundation/)** — principes, règles, glossaire.
6. **[01-product/](01-product/)** — proposition de valeur, modules, personas.
7. **[02-domain-model/](02-domain-model/)** — concepts métier, relations, cycle de vie.
8. **[03-business/](03-business/)** — stratégie marché et modèle économique.
9. **[04-architecture/](04-architecture/)** — structure technique.
10. **[05-decisions/](05-decisions/)** — Architecture Decision Records (ADR).
11. **[CURRENT_PRIORITIES.md](CURRENT_PRIORITIES.md)** — focus actuel et questions ouvertes (mis à jour régulièrement).
12. **[playground/](playground/)** — brouillons et expérimentations avant intégration dans la structure principale.

**MASTER_CONTEXT.md** fournit une vue d'ensemble de haut niveau du repository et oriente vers les documents canoniques.

**AGENTS.md** explique comment les assistants IA doivent interagir avec le repository.

Les couches suivent cette hiérarchie :

```text
Vision
    ↓
Foundation
    ↓
Product
    ↓
Domain Model
    ↓
Business
    ↓
Architecture
    ↓
Decisions
```

Vision est le document de plus haut niveau. Foundation reste la première couche du repository.
